# Changelog

## 0.1.0

- First standalone version of the local companion runtime for [HouseCraft Plugin](https://github.com/pankajvaghela/housecraft-plugin).
- Includes the draft one-house project format, a two-room example and one renovation variant.
- Validates projects with the local CLI and serves a read-only preview on localhost.
- Switch between house versions in 3D, review measurement evidence, and open or download complete project JSON. The viewer flags example dimensions so you can replace them with your own.
- Supports single-level homes and proxy furniture. GLB assets, community viewer plugins, in-browser geometry editing and deployment are outside this version.
